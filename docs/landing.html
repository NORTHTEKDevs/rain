RAIN-Net v0.1 — a new generative-AI architecture class

474/474 tests green CPU-trainable reference impl 2026-05-24

A composition engine built on Vector-Symbolic-Architecture hypervectors. Knowledge in addressable memory, skills as compiled procedures, reasoning as a verifiable trace. Architecturally distinct from any LLM, with measurable structural advantages on cost, audit, and continual learning.

What ships in v0.1

9 architectural modules

HV substrate · encoder bank · MoA router · hierarchical memory · verifier head · symbolic verifier · distillation · active learning · skills.

4 bundled deterministic skills

math_solver · date_math · unit_converter · regex_extractor. Each routed via HV-similarity + regex trigger patterns.

Live LM generation

Loads trained HYMN-Plus checkpoint through the MoA router. Real text, not stubs.

Multi-turn session memory

Episodic recall via HV cosine — works at 20+ turn horizons, unlike fixed-window LLMs.

Real Ollama distillation

220 facts across 4 domains, $0 cost via local llama3.2:3b. Pipeline + active-learning loop included.

HTTP API + Docker

rain-serve + Dockerfile. POST /query returns full AuditReport JSON with cited facts and confidence.
